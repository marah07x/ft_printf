# Printf

## Description

Printf project is part of the 42 curriculum.The goal of the project is to recreat the behavior of the **printf()** function without implement the buffer management of the original **printf()**.

## Instructions

- make -> builds libftprintf.a
- make clean -> deletes object files
- make fclean -> deletes object files + libftprintf.a
- re -> deletes object files + libft.a then rebuild libft.a from the start

### How to run the project

1) Clone the repo of the project
2) Use **cd** to get into the directory
3) Use make to build the libftprintf.a
4) Run the code by simply compiling the main with the libftprintf.a
```c 
cc main.c libftprintf.a
```
